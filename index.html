How the GPA is calculated

Each course percentage comes from the weighted average of its assessments. Percentage maps to a grade point, and the GPA is the credit-weighted mean of those points:

GPA = Σ (grade_point × credit_hours) / Σ credit_hours

4.0 scale: A 93+ = 4.0 · A− 90 = 3.7 · B+ 87 = 3.3 · B 83 = 3.0 · B− 80 = 2.7 · C+ 77 = 2.3 · C 73 = 2.0 · C− 70 = 1.7 · D 60 = 1.0 · F = 0. Assessments with no score yet are excluded, so the number is always "GPA so far".

Quick model of the app

Cadence is one HTML file. There is no server, no account and no analytics. Every record you create is written to localStorage under the key cadence.v1 the moment you save it, and read back when the page loads. That is why data survives a reload — and why it does not follow you to another browser unless you export a backup.

One-device data. Private/incognito windows, "clear site data", and iOS Safari's 7-day eviction for unused sites can all wipe localStorage. Export a backup weekly if the work matters.

1. Daily plan

Tasks get a priority (high / medium / low), course, estimate and a date. The Today screen shows the current day's list sorted by priority, with a completion bar; the plan view can move between days, carry unfinished work to tomorrow, and shows the week at a glance. Priority beats due date in sorting because a high-priority task due Friday deserves today's attention more than a low-priority one due tomorrow.

Needs: nothing. Without anything: fully functional offline.

2. Study reminders

Two jobs. Deadline alerts: add an exam or deadline and it shows a countdown chip that turns amber at 7 days and red at 2 days, plus appears in the Today "due soon" panel. Spaced repetition: give a topic and a first study date, pick an interval ladder (1·3·7·14·30 days by default), and Cadence creates one reminder per interval. Tick each off as you do it.

Needs: optional browser notification permission for system alerts. Without it: alerts still appear in-app on every visit — the app checks on load and every 60 seconds while open.

3. Lecture notes — recording, transcription, summary, questions

Recording uses MediaRecorder, which works in Chrome, Edge, Firefox and Safari 14.1+. You get a timer, a stop button and a downloadable audio file for that session.

Live transcription uses the Web Speech API (SpeechRecognition). Support: Chrome and Edge on desktop and Android, Safari 14.1+ with the WebKit prefix. Firefox does not support it. It is also usually unavailable on plain http:// — a secure context is required.

Summarising and question generation run locally with a classical extractive algorithm: sentences are scored by term frequency, position and length, then the top ones are kept; questions are built from definitional and causal sentences plus keyword cloze cards. No model API, no key, no upload.

Without a microphone or speech support: type or paste the lecture into the same box and press Summarise / Generate questions — the exact same pipeline runs. The app states which capabilities it detected at the top of the view rather than failing silently.

4. Assignments

Title, course, due date, weight and status (not started → in progress → submitted → graded). Overdue items get a red edge; the stats row totals open work, work due this week and the percentage of your grade already submitted. Filter between open, submitted and all.

Needs: nothing.

5. Focus & distraction control

A Pomodoro timer with 25 / 5 / 15-minute modes, a countdown ring, and automatic hand-off from focus to break. Before starting you write down whatever is pulling at you — the point is to park it, not fight it. Completed focus sessions are logged with the linked task, and daily minutes are totalled on the screen and on Today.

Distraction-free opens a full-screen timer that covers the app, so the next tab switch is a conscious decision.

Needs: nothing. The timer uses setInterval and keeps accurate time from timestamps even if the tab is throttled in the background.

6. Email & file organization

File naming: fill in course, type, title, date, version and initials, choose a pattern, and get a normalised filename — lowercase, spaces to hyphens, accents stripped, unsafe characters removed, ISO dates, zero-padded versions. Saved names build a small log so you can see your own consistency.

Gmail filters: the app builds a Gmail search query and a matching filter XML in Gmail's import format. Download the .xml, then in Gmail go to Settings → Filters and Blocked Addresses → Import filters → Choose file → Create filters. You review each one before it is applied.

Needs: no API key and no OAuth — and it never asks for your password. Without Gmail access: the search query still works when pasted into Gmail's own search box, and the file-naming tool is entirely offline.

7. Weekly review

One card per ISO week. It shows the week's real numbers (tasks completed, focus minutes, notes captured, cards reviewed, reminders cleared), lets you tick off what carries into next week, and stores three free-text fields: wins, friction, and three commitments. Past weeks stay readable, so you can see whether the same friction keeps recurring.

Needs: nothing.

8. Grades & GPA

Add courses with credit hours, then add assessments with a score and a weight. Cadence computes the weighted course percentage, a letter grade, and a credit-weighted GPA. Assessments without a score are excluded so the GPA reflects graded work only.

What-if projects a course percentage if you score a given mark on the outstanding weight, so you can see what you actually need on the final.

Needs: nothing. This is your own arithmetic, not an official transcript.

Added feature 1 — Flashcards (spaced repetition)

Why: rereading notes feels productive but barely moves retention; retrieval practice does. Cards use a simplified SM-2 algorithm — each rating (Again / Hard / Good / Easy) adjusts the interval and ease factor, so weak cards return in minutes and strong ones in weeks. Cards can be created by hand or generated in bulk from a lecture note's generated questions.

Needs: nothing.

Added feature 2 — Habit streaks

Why: grades are downstream of boring daily behaviour — sleep, reading, showing up. A 14-day grid with a current streak and a best streak makes a missed day visible without a lecture. Consistency percentage is shown per habit so a broken streak does not erase the evidence of the good weeks.

Needs: nothing.

Added feature 3 — Backup & data export

Why: a localStorage-only app is exactly as durable as one browser profile. JSON export makes the data portable between laptop, phone and browser, and makes "I cleared my cookies" a ten-second fix instead of a lost semester. Merge keeps both sets; replace wipes first. Both paths validate the file and refuse anything that is not a Cadence backup.

Needs: nothing.

A typical day

  1. Morning — plan (5 min). Open Today, then Daily plan. Add the day's real work with priorities. Three high-priority items is a full day; everything else is optional. Check Reminders for countdowns and clear any due review.
  2. Lecture — capture. Open Lecture notes, hit record, and let the transcript fill in. If speech recognition is unavailable the banner tells you, and you type instead. Press Summarise and Generate questions, then save.
  3. Between classes — recall (10 min). Go to Flashcards and clear the due queue. "Generate questions" on a note can push straight into new cards.
  4. Deep work — focus. Pick the task in Focus timer, park your distractions in the box, and run a 25-minute block. Take the break; the timer hands off automatically.
  5. Afternoon — submissions. Check Assignments, move anything you finished to submitted, and look at what is due in the next three days.
  6. Evening — file and log. Name today's files in Files & email so tomorrow's search works. Tick your Habits.
  7. Sunday — review. Open Weekly review, read the numbers, write wins and friction, set three commitments. Then Backup → download JSON.
